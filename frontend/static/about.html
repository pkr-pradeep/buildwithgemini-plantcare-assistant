Meet PlantCare Assistant

An autonomous, multi-modal AI botanical specialist designed to help houseplant owners, indoor gardeners, and plant lovers nurture thriving green spaces.

🌟 What PlantCare Assistant Can Do

🌿

Firestore Botanical Database

Queries live plant records from a Google Cloud Firestore database (`house_plants` collection) by scientific name, light level, care difficulty, and toxicity.

💧

Environmental Watering Calculator

Calculates exact watering volumes (mL / fl oz) and watering frequencies based on pot diameter, room temperature, and relative humidity.

🎨

Imagen 3 Visual Generation

Generates high-resolution plant care reference images, blooming visuals, and leaf diagnostic guides using Google's `imagen-3.0-generate-002` model.

📹

Omni Time-Lapse Videos

Renders short botanical growth and blooming videos using Google's Omni model (`gemini-omni-flash-preview`), saved directly to Google Cloud Storage.

📷

Photo Health Diagnosis

Upload or snap photos of yellowing leaves, pest damage, or soil conditions for instant AI visual diagnostic recommendations.

📅

iCalendar (.ics) Reminders

Generates exportable `.ics` calendar files to add recurring watering reminders directly into Google Calendar or Apple Calendar.

🎤

Voice Speech Input

Integrated hands-free microphone input using Web Speech API for real-time speech-to-text queries in the browser.

🌤️

Live Microclimate Weather Care

Fetches real-time local temperature and humidity via Open-Meteo to adjust watering and humidity care advice for indoor microclimates.

🛒

Local Nursery Finder

Locates nearby garden centers, plant nurseries, and florists with direct Google Maps directions links.

🪴

Room-by-Room Houseplant Organizer

Analyzes indoor rooms (Bathroom, Living Room, Bedroom, Office) and window orientations to recommend optimal plant positioning and light guides.

🐾

Pet Safety & Toxicity Badges

Prominently highlights whether a plant is toxic or safe for cats and dogs (`🐾 ⚠️ TOXIC` vs `🐾 ✅ PET-SAFE`).

📄

Printable PDF Care Exporter

One-click PDF Export (`window.print()`) button on care guides for printing or saving downloadable plant care sheets.

⚙️

API Key Settings Provision

Allows users to input replacement Gemini or Google Maps API keys if default system credentials ever expire.

🧠

Vertex AI Memory Bank

Remembers user plant collections, personal preferences, and strict pet/allergy safety rules across multi-session conversations.

📊

Native A2UI Card Rendering

Renders interactive A2UI card layouts, images, and column metrics natively in the chat interface.
